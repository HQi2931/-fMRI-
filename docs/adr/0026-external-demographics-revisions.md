# ADR 0026：外部指标的人口学修订

- 更新日期：2026-10-09

## 决定

外部人口学表复用现有只读解析器，按已纳入的 subject_id 对齐。修订独立绑定外部导入 ID、纳入哈希、映射后的内容哈希及源表哈希，不创建虚假的预处理数据集。缺失、重复和多余受试者阻止登记；分组仍以人工确认的影像纳入记录为准。

统计设计冻结外部人口学修订 ID/hash，协变量数值从该修订读取并按影像顺序装配。新修订使引用旧人口学的下游方案失效；审批与 Worker 继续使用现有状态机。模型仅接收列名和修订摘要，不接收原始表行。

## 边界

数值转换、缺失值策略、中心化、矩阵秩及自由度由统计装配器和领域模型验证。此决策补充 ADR 0025，不改变其图像纳入或空间定位要求；配对影像接入另行实现。
