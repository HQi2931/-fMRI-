# ADR 0024：Work 预处理与数据分析双 Agent

- 状态：Accepted
- 文档类型：ADR
- 维护者：system_architect
- 决策日期：2026-10-08
- 更新日期：2026-10-08
- 关联：[系统设计](../architecture/system-design.md)、[组统计设计](../domain/statistics.md)

## 背景

Work 既需要规划和启动预处理，也需要建立组统计设计、检查校正和解释结果。单一提示词和单份草稿会混淆两类任务，并使交接时的方案归属与工具权限难以审计。

## 决定

Work 保持一个用户对话，由应用层确定性路由到两个业务 Agent：预处理 Agent 与数据分析 Agent。它们共用模型网关、会话、工作流和 MATLAB Worker，但分别使用角色提示词、模型动作白名单及独立草稿；不增加第三个模型型协调 Agent。

角色选择由用户界面或服务端路由确定。短续接沿用当前角色；明确任务意图可以切换角色。预处理到分析的任务依赖和缺失指标的反向交接以会话中的结构化记录表示，记录数据引用及证据哈希。接收方只获得必要摘要，并重新读取、校验服务端状态；模型只能读取状态和提出方案，执行仍由服务端审批与一次性确认入口控制。

统计能力目录将 DPABI 函数入口、设计要求、结果合同、执行状态和验证状态分开记录。只有接通应用设计装配、固定模板和结果登记且已通过对应验证的能力才可执行。六类统计与 FDR/GRF 已纳入现有执行路径，并在本机 MATLAB R2024b、SPM25、DPABI V9.0_250415 上通过真实执行 smoke。

## 后果

旧 Work 草稿在读取时归属预处理 Agent。统计草稿单独保存；角色及工具审计记录角色。已登记统计设计的来源固定标记为 analysis。会话共享工作流状态，但不会共享另一角色的私有草稿或完整对话历史。

## 验证边界

仓库提供需单独授权的小型真实 MATLAB smoke；DPABI 函数文件存在不代表本机验证通过。六类统计、双样本 t 后 FDR、配对 t 后 GRF、相关 FDR 与三组 ANOVA GRF smoke 已在本机通过。Work 已连接统计草稿到正式设计审批、运行、校正证据登记、结果簇表、DPABI 图谱定位、簇表到轴向切片联动及 Markdown/JSON 报告导出。真实 Slow-1 DemoData 也已完成小样本双样本 t/FDR 执行；由于导入空间未确认，不生成脑区标签。外部目录正式登记、独立检查与纳入确认仍待实现。
