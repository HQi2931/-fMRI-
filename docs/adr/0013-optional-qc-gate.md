# ADR 0013：QC 由运行请求显式选择

- 状态：Accepted
- 文档类型：ADR
- 决策日期：2026-09-21

## 背景

头动 QC 是研究流程的重要证据，但不同项目会在指标计算后采用独立的质控流程。将 QC 固定为所有后续操作的阻断条件，会阻止用户在明确知情的情况下继续整理或统计已完成的指标产物。

## 决定

每个预处理或指标运行在创建时记录 `qc_mode=require|skip`。`require` 保留自动头动检测与人工审批；`skip` 在产物登记完成后进入成功状态。等待 QC 的运行也可通过追加式 `qc_skip` 记录继续。统计设计只能绑定已批准 QC review，或绑定来源运行的 QC 跳过记录；两种来源均写入冻结设计与结果报告。

## 后果

跳过 QC 不会删除、改写或伪造头动检测结果，也不会解除指标谱系、输入清单、受试者顺序和掩膜校验。报告需要显式说明 QC 已跳过及决策原因。
