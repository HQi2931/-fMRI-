# ADR 0032：统计方案冻结图谱选择及内容版本

- 状态：Accepted
- 文档类型：ADR
- 维护者：system_architect
- 决策日期：2026-10-10
- 更新日期：2026-10-10
- 关联：[计划 0013](../plans/0013-work-dual-agent-analysis.md)、[脑区定位合同](../domain/roi-ml-localization.md)

## 背景

已有统计结果可以查询本机 DPABI 图谱，但只在查询中选择图谱不能保证分析方案和复现报告使用同一版本。图谱文件或标签表变化后，以文件大小和修改时间为键的缓存也可能保留旧头信息或标签。

## 决定

正式统计设计创建请求增加可选 `atlas_id`。服务端读取本机支持的 AAL、AAL3 或 Brodmann 图谱，绑定实际名称、影像与标签文件的联合 SHA-256、MNI 空间、逆 NIfTI 仿射最近邻方法及 26 邻域约定。该 `localization_plan` 进入不可变方案和方案哈希；执行完成后进入冻结复现报告及结果 bundle。统计数值设计的原合同不变。

Work 确认页仅在 AAL 实际可用时建议 AAL；用户可以选择其他可用图谱或暂不选择。图谱选定不代表输入已处于 MNI 空间。方案校验、批准及启动前复核图谱内容；选择和版本不能在定位查询中替换。改变图谱须创建并审查新方案。

未指定图谱的设计和历史结果保持兼容，允许明确查询其他可用图谱。真实结果没有簇时，先返回正常空结果；零显著体素无需图谱或空间定位检查。Mock 结果继续禁止科研定位。

图谱头和标签的解析缓存有大小上限，以实际内容 SHA-256 为键；即使大小和时间戳不变，内容改变也使缓存失效。缓存仅减少重复解析，完整性仍重新读取文件验证。正式状态、方案、消息和任务继续复用现有 SQLite，影像、脚本和报告保存在文件系统；不新增缓存数据库或独立服务。

## 后果

结果定位可追溯到已审查的图谱版本。图谱不可用或改变会阻止旧方案，已有统计结果及失败证据仍保留。读取文件内容增加少量 I/O，但不将可变缓存当作科研事实。真实验收范围及未完成事项见[验证记录](../development/mvp-verification.md)。
