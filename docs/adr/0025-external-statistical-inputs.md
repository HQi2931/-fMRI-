# ADR 0025：外部指标的独立纳入凭据与统计输入

- 状态：Accepted
- 文档类型：ADR
- 维护者：system_architect
- 决策日期：2026-10-09
- 更新日期：2026-10-09
- 关联：[ADR 0024](0024-work-dual-agents.md)、[组统计](../domain/statistics.md)

## 背景

用户已有的 DPABI 指标图没有本系统预处理运行、TR 或处理谱系凭据。将它们写成预处理产物会掩盖未知信息，而现有统计执行器仍需要冻结输入、明确纳入决定和同网格 mask。

## 决定

外部目录由独立导入记录保存只读检查与人工纳入决定。检查记录逐影像 subject、组别、指标缩放、NIfTI 网格、大小和 SHA-256；站点限定的文件名保留站点前缀，避免不同站点的局部编号合并。空间与处理历史保持未知，只有审核者明确选择的空间写入纳入凭据。mask 由审核者选择，必须在导入根内且与指标图同网格。

统计设计使用 `qc_source=external_import`、导入 ID 与纳入哈希绑定该来源。纳入后的详细查询提供受试者影像和 mask 的稳定不透明引用，以及包含目录检查和纳入决定的输入清单哈希。这些引用不伪装成 `ArtifactRow` 或预处理运行。

现有统计 PlanRevision、审批、Worker、MATLAB 模板和结果状态机继续使用。编译器从服务端纳入记录生成只读 staging 绑定；Worker 再次验证项目边界、引用、文件大小与哈希，复制到独立 attempt 后调用 DPABI。目录或 mask 变化使旧设计失效。结果坐标空间来自对应纳入记录；零显著体素直接报告无显著差异及无可定位脑区。

## 后果与边界

外部图的未知 TR、频带、去噪和平滑信息不会获得虚假的 verified 预处理谱系。报告保留外部来源与纳入哈希。真实进程 stdout/stderr 仍作为运行日志产物保存；统计复现清单使用固定模板产生的 canonical 统计日志，空进程日志不登记为非空产物。

当前目录适配器提供每名受试者一张体积指标图的来源，组目录用于组间设计，单样本与相关/回归可以显式忽略组标签。外部配对、人口学 revision 接入和 Work 对话选择外部来源仍需要补齐；这不改变双 Agent 计划的完整验收范围。
