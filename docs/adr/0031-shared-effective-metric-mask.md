# ADR 0031：相同有效指标掩膜的组级引用

- 状态：Accepted
- 文档类型：ADR
- 维护者：matlab_dpabi_engineer
- 决策日期：2026-10-10
- 更新日期：2026-10-10
- 关联：[ADR 0029](0029-work-analysis-handoff-evidence.md)、[计划 0013](../plans/0013-work-dual-agent-analysis.md)

## 背景

预处理按受试者复制并登记 DPABI 实际使用的有效指标掩膜。统计入口要求组级掩膜及共同指标掩膜引用；即使 DPABI 为全组使用同一有效文件，旧登记方式仍生成多个受试者级引用，阻止内部数据进入分析。

## 决定

执行端先验证全部实际指标和有效掩膜，再比较逐受试者掩膜的 SHA-256、大小、空间、物理网格、体素大小及清单来源，并读取每个文件复核内容。当全部一致时，在独立 attempt 下复制共同内容并登记唯一组级 `preprocessing.brain_mask`；各指标引用这个实际相同的内容。原始受试者产物保留为 `preprocessing.subject_brain_mask`，不修改数据或原有处理证据。

组级来源记录 `identical_effective_masks` 方法及逐受试者文件引用、大小和哈希。分析交接同时保存并复查这些原始掩膜；任一来源变化使凭据失效。统计设计的共同掩膜与网格约束保持不变。

不同有效掩膜不通过本步骤自动求交集、合并或重采样；其统计掩膜仍须另行明确。组级引用不证明影像已标准化，不改变原生空间标记或 QC 纳入决定。

## 验证边界

确定性回归覆盖内容、空间、网格、清单差异、执行验证后的文件变化、重复受试者及下游交接失效。`scripts/verify-internal-statistics.py` 已显式 opt-in 完成六份合成输入的真实预处理/QC/交接/两样本 t/FDR 服务验收，完成证据见[验证文档](../development/mvp-verification.md)。内部网页、真实模型规划及其他统计能力的最终范围仍按计划审计。
