# ADR 0033：分析 Agent 使用确定性结果事实

- 状态：Accepted
- 文档类型：ADR
- 维护者：system_architect
- 决策日期：2026-10-10
- 更新日期：2026-10-10
- 关联：[计划 0013](../plans/0013-work-dual-agent-analysis.md)、[ADR 0032](0032-frozen-statistical-atlas.md)

## 背景

结果解释需要已登记的检验方向、校正阈值、定位和 ROI 描述。向模型发送完整统计报告会同时暴露逐受试者设计信息，且无法保证模型正确区分簇存在、坐标空间已知及实际图谱可定位。

## 决定

服务端从冻结报告及登记清单生成强类型方法摘要，复核报告 bundle、设计与清单绑定。实际校正和软件信息只从通过路径及内容哈希检查的证据产物读取。历史缺少有效摘要的报告仍可读取原文，摘要明确不可用。

分析角色的结果明细工具只返回有界的确定性方法、推断及簇摘要，不发送完整报告、逐受试者设计矩阵或协变量取值。增加只读定位与簇 ROI 汇总工具，在检查项目和允许的运行后调用既有科研查询。定位沿用方案冻结的图谱；历史未选择图谱时要求明确选择。ROI 只返回按组别和条件汇总的计数、均值、样本标准差和范围，不返回个人标识或逐受试者值，也不计算第二次 p 值。

这些工具仅属于分析角色，预处理角色不能调用。每次请求继续使用既有总预算、工具脱敏与审计机制，不引入执行权限、模型 Agent 或状态机。提示词区分动作与工具，要求以已核验事实解释，禁止以空结果证明两组等价、将总体 F 赋予组间方向或虚构文献机制。

分析请求的初始上下文也提供当前角色绑定运行的确定性摘要，最多五份结果。用户要求解释、定位或 ROI 时，在已校验项目/运行范围内复用相同的只读查询；初始 ROI 仅描述首个登记簇并明确标注选择，不泛化到其他簇。没有工具能力的模型仍可使用这些事实；工具模型可继续有界查询其他簇。查询失败只返回阻断代码，不猜测标签或数值，不启动执行。

结果面板使用同一方法摘要展示检验、方向、自由度和阈值。零显著体素是正常完成；已知原生空间与未知空间分别汇报。图谱定位是否成功以实际查询为准，不能仅由簇存在推断。

## 后果

模型和页面使用同一组可追溯事实。无法核验的结果返回明确状态而不拼接猜测。大结果截断簇或标签时保存总数及截断标志；完整产物仍由既有下载入口提供。
