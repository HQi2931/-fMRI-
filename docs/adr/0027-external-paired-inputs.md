# ADR 0027：外部条件影像的显式配对

- 更新日期：2026-10-09

## 决定

外部目录检查增加显式 `paired_conditions` 布局，一级目录为恰好两个条件，文件编号为受试者。每个条件内编号唯一，两个条件必须覆盖相同的受试者集合；缺失或重复阻止纳入。默认 `grouped` 保留组间比较语义，不根据目录名自动改变布局。

条件和受试者共同决定影像引用。纳入清单保持逐受试者记录；统计设计根据明确的条件顺序消费每名受试者的两张图。检查、确认、方案创建和 Worker 编译均复核配对关系及来源哈希，继续使用现有统计审批和执行状态机。

## 边界

配对布局首期用于配对 t 检验；不自动合并独立组目录或推断纵向扫描关系。条件顺序决定差值方向。人口学表仍每名受试者一行；配对 t 不接受跨条件重复的静态协变量，因为它们与 DPABI 的受试者回归项共线。不支持首期范围外的混合效应或重复测量 ANOVA。
