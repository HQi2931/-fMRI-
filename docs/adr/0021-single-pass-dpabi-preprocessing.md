# DPABI 预处理单次运行

- 状态：Accepted
- 文档类型：ADR
- 维护者：system_architect
- 决策日期：2026-09-30
- 替代关系：取代 [ADR 0020](0020-dparsf-draft-and-t1-review.md) 中的独立 T1 准备与审查接口

## 背景

DPARSFA 原生按配置执行所选预处理和指标步骤。先前包装脚本把指标拆成第二次 `DPARSFA_run`，同时暴露独立 T1 准备、证据哈希和人工审查 API，增加了运行分支。

## 决策

用户确认完整方案并逐次授权启动后，一个 Worker 作业在独立 staging 中准备 T1，然后以完整配置调用一次 `DPARSFA_run(..., 0)`。调用返回且无错误后，程序统一检查并登记功能像、指标、组织图、模板、形变场及可选检查图。不再提供独立 T1 准备运行、复用或中途审查接口，也不计算额外的 T1 证据哈希。

冻结方案与输入清单哈希用于启动前确认数据与获批计划一致；最终产物 SHA-256 用于登记文件身份与完整性。这两类检查不构成步骤间审批或运行暂停。原始数据保持只读，GUI 关闭，产物缺失或不完整仍按作业失败处理。

## 后果

Work 参数面板、草稿版本控制和整体方案确认沿用原有合同。移除独立 T1 API 和 `RunCreate.t1_preparation_run_id`；既有历史记录保持可读。指标产物按 DPABI 实际 `Results` 目录收集。真实 MATLAB T1/DARTEL/指标组合尚未在本轮验证，继续标记未实测。
