# ADR 0023：Work 阶段反馈与校验后的正式回答

- 状态：Accepted
- 文档类型：ADR
- 维护者：system_architect
- 决策日期：2026-10-07
- 更新日期：2026-10-07
- 关联：[ADR 0019](0019-conversation-streaming.md)、[计划 0012](../plans/0012-work-conversation-ux.md)

## 背景

Work 的模型 answer 在科学参数、引用与动作校验之前不能代表实际结果。只提取顶层 answer 仍可能展示内部字段、冗长参数清单或模型错误的执行声明；服务端最终整理会造成正文先出现再被替换。

## 决定

沿用现有 POST SSE、Provider 原生流式接收和断连后的幂等收口。Work 在模型请求、工具派发和规划校验实际开始时发送固定中文 status，不发送未校验模型正文 delta；校验与保存成功后通过 final 展示正式正文、方案与工具审计。前端 Work 同时忽略旧服务端发送的预览 delta。状态不包含文件路径、工具参数、模型原文或授权。

Chat 继续提供正文 delta。reset 保留，用于隔离模型轮次；Work 的状态反馈不宣称成功、批准或执行。不存在可靠进度时不生成百分比。断连仍保留原幂等键，重试恢复持久化结果。

本决策取代 ADR 0019 中 Work 顶层 answer 暂存预览部分，其他传输、事务和执行边界继续有效。

## 后果与验证

Work 正式正文需要等本轮处理完成，但等待期间可看到实际发生的处理阶段，正文与草稿不会先展示另一份未通过校验的版本。测试覆盖无效执行声明不出现在 SSE、工具阶段反馈、Chat 增量、Work 正式收口、请求隔离和断连重放。完整实际浏览器阶段验收仍按计划 0012 执行。
