# ADR 0035：统计输入保留已完成预处理的历史环境

- 状态：Accepted
- 文档类型：ADR
- 维护者：system_architect
- 更新日期：2026-10-10
- 决策日期：2026-10-10
- 关联：[统计合同](../domain/statistics.md)、[计划 0013](../plans/0013-work-dual-agent-analysis.md)

## 背景

内部网页验收发现，新统计设计虽冻结当前环境，启动时仍递归要求已经成功且通过QC的预处理计划匹配当前环境。统计适配新增入口指纹后，既有合格指标因此不能进入新统计运行。历史产物由其实际来源运行解释，不应被当作将在新环境再次执行的预处理计划。

## 决定

只有来源运行处于 succeeded 时，递归复核来源计划使用该来源计划保存的历史环境锁。统计方案自己的当前环境校验保持不变，环境在统计批准后变化仍阻断执行。来源尚未成功时继续使用当前环境校验，不扩大运行或QC权限。

仍重新检查源数据及manifest、已登记指标和掩膜内容、处理谱系、QC、交接哈希、Skill及Tool绑定；本决定不豁免输入或产物变化，也不自动更新审批。历史软件环境仍由来源方案及实际运行证据保留。

## 后果与验证

新环境可以对历史环境下已完成的合格体积指标建立单独确认的统计设计。回归分别覆盖成功和失败的来源环境边界，并证明统计自己的环境变化仍阻断；既有输入变更与交接失效矩阵保持通过。实际网页验收在独立复制的合成预处理工作区进行，原数据库和产物不修改。
