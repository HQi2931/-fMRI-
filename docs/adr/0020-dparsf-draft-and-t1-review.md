# DPARSF 参数面板与 T1 准备审查

## 决策

Work 的参数面板直接编辑服务端结构化草稿；保存不调用模型、不编译、不授权执行。草稿修改使用基准哈希与幂等键，旧确认失效。模型建议保持待审查状态，未知采集参数不自动补默认值。

T1 分割独立于标准化建模。DARTEL 必须使用 New Segment 输入以及绑定冻结受试者集合的模板和形变场。根据用户后续明确要求，T1 重定向、裁剪、配准、分割和 DARTEL 在同一次预处理运行内执行，不增加中途人工审查或授权。输入配对、准备产物和依赖由程序验证，检查图供运行后自愿查看。所有计算由固定模板启动，原始输入只读，不能依靠文件名声明准备完成。

## 后果

前端增加 Work 内嵌参数编辑面板。整体方案确认和启动授权沿用现有流程；独立 T1 准备及审查 API 仅作为可选高级能力，不是正常预处理的前置条件。旧冻结方案维持原有参数解释；新能力的真实 MATLAB 验证需独立授权。安装源码只作为只读接口证据，不修改安装目录。
