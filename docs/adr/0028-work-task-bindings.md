# ADR 0028：Work 角色任务引用与确认作用域

- 状态：Accepted
- 文档类型：ADR
- 维护者：system_architect
- 决策日期：2026-10-09
- 更新日期：2026-10-10
- 关联：[ADR 0024](0024-work-dual-agents.md)、[计划 0013](../plans/0013-work-dual-agent-analysis.md)

## 背景

网页统计运行目前依赖浏览器缓存恢复，服务端会话没有保存统计运行；历史预览的审批入口也未绑定当前分析草稿。角色切换不应丢失任务，也不应批准另一角色或过期草稿。

## 决定

会话持久保存前台角色，以及两个角色各自的草稿哈希、当前统计提案引用、正式方案与运行引用。这些是已有 PlanRevision/WorkflowInstance 的引用，不建立新的状态机。旧会话的运行归属预处理角色；新统计提案、方案、运行只能由服务端写入对应绑定。

从 Work 创建的统计方案绑定会话、服务端提案哈希、提案消息和草稿哈希。创建时逐项比对提案的项目、输入、设计和校正；校验、审批与启动时再次检查角色、草稿和正式方案引用。服务端 writer 事务内复查并原子保存方案/运行和会话引用，幂等重放不重复绑定或改变当前前台任务。独立统计接口保留不带会话的兼容路径。

手动切换通过版本受控接口保存角色，保留各自草稿与运行。网页从会话绑定恢复方案/运行，只给当前角色的当前提案开放确认入口。分析的上游预处理来源与分析运行分开读取。

## 后果

关闭页面、清空缓存或换浏览器仍能读取相同任务。新草稿使旧提案的确认失效；历史结果仍可读取。迁移不猜测已有统计缓存对应的会话，旧独立统计方案不被追溯绑定。两个 Agent 仍共用既有执行器、审批与运行状态。
