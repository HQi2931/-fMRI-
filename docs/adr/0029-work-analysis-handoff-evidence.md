# ADR 0029：预处理到分析的完整交接凭据

## 决定

复用会话消息的持久化结构保存交接，不新增运行状态机。服务端从来源运行、不可变方案、数据集清单、QC 决定及已登记产物生成交接凭据；凭据包含逐受试者指标、版本来源、完整处理谱系、掩膜及内容哈希。身份由数据凭据确定，处理状态和模型解释不参与身份计算。

接收方重新读取相同来源并检查产物路径、大小和 SHA-256，比较完整凭据；QC 未决、失败运行、清单变化、缺失指标或产物变更阻止接收。统计方案保存所接收的完整凭据，并在校验、审批和启动前重新检查。重复接收相同凭据不改变方案身份或创建运行；草稿和已登记历史结果保留。

模型仅获得交接编号、状态、必要需求摘要及数量，不获得另一角色的私有参数草稿。执行仍需已有独立统计审批和逐次确认。

## 验证边界

结构化凭据和故障路径通过服务端回归验证；内部预处理到分析的完整真实 MATLAB 和网页验收按计划 0013 继续推进。
