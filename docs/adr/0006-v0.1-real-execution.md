# ADR 0006：v0.1.0 纳入真实执行闭环

- 状态：Accepted
- 日期：2026-09-03
- Supersedes：`docs/plans/0004-release-roadmap.md`

## 决策

`v0.1.0` 包含受批准 `SkillPlan`/统计设计到类型化 ToolRuntime、受控 MATLAB/DPABI 执行、真实证据登记和确定性报告的闭环。原 0004 中“真实执行推迟到 v0.2.0”的决定不再适用。

真实执行同时受四道门保护：请求选择 `execution_backend=matlab`、逐次 `real_execution_confirmed=true`、`RSFMRI_ENABLE_REAL_EXECUTION=true`，以及只读环境探测返回 `ready=true`。Mock 仍是默认值和 CI 路径。

本机 MATLAB、SPM 和 DPABI 的路径由用户在前端首次配置。系统不要求所有用户安装相同版本：版本号是用户填写的证据标签，默认 `unspecified`，只用于环境锁和运行记录；实际可用性以当前路径上的受控入口探测、dry-run 和目标机器 smoke 为准。配置保存于工作目录的 `.rsfmri-environment.json`，不进入 Git、数据库事件或科学结果。

## v0.1.0 科学范围

- 预处理/指标：按冻结 SkillPlan DAG 执行，保留输入只读、Artifact lineage、NIfTI 元数据和 QC gate。
- 统计：单样本、两独立样本、配对 t 检验；可选 FDR 或 GRF 校正。
- 效应量：单样本/配对使用 `t / sqrt(n)`；独立样本使用基于两组样本量和 residual DF、带小样本校正的 Hedges' g。
- 簇表：以校正图为来源（无校正时使用未校正图），26 邻接，坐标由 NIfTI affine 转毫米；不自动推断脑区名称。
- 结果：设计矩阵、contrast、T 图、校正图（如配置）、效应量图、簇表、日志和软件版本证据缺一不可。

相关和一般回归不属于 v0.1.0；Provider smoke 仅验证固定的无受试者信息 schema/连通性请求。

## 失败关闭与授权边界

客户端不能提交 MATLAB 文本、Shell、JobSpec 或任意路径。Worker 根据已批准计划、审批记录和已登记 Artifact 编译 JobSpec；工具锁、环境锁、manifest hash、输入元数据和产物新鲜度任一失配均失败关闭。原始数据目录只读，运行写入隔离工作目录。

不同 MATLAB/SPM/DPABI 版本和目录布局可能存在兼容差异。用户选择目录不等于兼容性证明；无法通过入口探测或 smoke 的环境必须失败关闭。

真实 MATLAB smoke、Provider 调用、GitHub 认证与外部发布分别需要执行时的人工授权；未授权时只允许 dry-run、Mock 和静态/类型化集成测试。
