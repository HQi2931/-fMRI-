# Chat / Work 模型理解与参数补全

- 状态：Implemented
- 文档类型：Plan
- 更新日期：2026-09-23
- 目标里程碑：Chat/Work 模型理解与参数补全
- 关联：[ADR 0014](../adr/0014-bounded-tool-loop.md)

目标：修复知识查询被误分为执行、Work 固定回复和自然语言参数不能编译的问题。

- Chat：已配置模型时对非寒暄消息进行语义分类并重写追问检索问题；失败时安全回退，不猜测执行。
- Work：模型只能返回自然语言、有限动作意图和参数草稿补丁；上下文包含历史与服务端状态。模型不能生成授权、项目标识、路径或直接调用工具。
- 参数草稿保存在会话消息 payload，逐轮合并。完整草稿经过既有参数模型检查后展示全部参数；用户明确确认该版本后才绑定服务端项目/清单并调用 Skill 校验编译。编译不等于批准或运行。
- 执行继续需要精确确认、当前计划哈希、工作区绑定和明确 QC 选择；模型输出不能设置确认标志。
- 验证仅用 Mock Provider 与合成 fixture；覆盖否定、追问、草稿纠正、模型故障、错误结构和审批边界。不启动真实 MATLAB。

公共 REST schema 保持不变；内部草稿为未批准状态，不是 Workflow 或科学结果。
