# 计划 0005：用户选择本机科学软件环境

- 状态：Accepted，纳入 v0.1.0
- 更新日期：2026-09-04
- 关联决策：[ADR 0006](../adr/0006-v0.1-real-execution.md)

## 目标

应用首次打开时提示用户配置本机 MATLAB、SPM 和 DPABI。系统不把某个厂商安装目录、MATLAB 版本或 DPABI 版本当成所有用户的前置条件；用户填写自己机器上的实际位置，服务端负责验证、探测和锁定本次运行使用的环境。

## 产品决策

1. 前端设置页提供首次配置表单，未配置时在其他页面显示入口提示。
2. MATLAB 使用可执行文件路径；SPM 和 DPABI 使用目录路径。路径由运行 API 和 Worker 的同一台本机访问。
3. 版本字段是用户填写的描述性证据标签，默认 `unspecified`，不作为精确兼容承诺。
4. 保存前严格验证文件/目录存在；软件后来被移动或卸载时，环境探测失败关闭，用户可回到设置页重新选择。
5. 配置保存在工作目录的 `.rsfmri-environment.json`，不写入 Git、数据库事件、计划内容或结果报告；环境锁只保存版本标签、入口指纹和哈希。
6. 运行时仍检查当前 DPABI 受控入口函数。不同版本的目录结构或函数签名可能不兼容，必须以本机 dry-run 和人工 smoke 为准，不能因用户填写了版本号就宣称兼容。
7. Mock 仍为默认后端；MATLAB 还必须同时满足配置开关、环境探测通过和逐次运行确认。

## 实施与验收

- API：`GET/PUT /api/v1/environment/config` 提供读取和保存配置；`GET /api/v1/environment/probe` 重新计算当前环境指纹。
- Worker：每次作业读取最新本机配置，避免 API 启动时的旧路径遮蔽用户刚保存的配置。
- 版本漂移：从“固定版本阻断”降为“用户可见警告 + 入口探测 + dry-run 审核”。
- 测试：覆盖缺失路径失败关闭、配置持久化/重载、版本标签进入锁哈希、前端首次提示和配置保存。
- 文档：所有示例只把固定版本作为示例标签，不再将其写成通用安装要求。

## 明确限制

本计划解决的是本机环境选择和边界控制，不承诺兼容任意 MATLAB/SPM/DPABI 组合。当前受控适配器仍以已验证的 DPABI 入口布局和参数投影为准；未知布局必须先通过 dry-run 和目标机器 smoke，失败时不得登记为科学成功。
