## 原始范围与完成条件

保持用户要求的两个业务 Agent，共用模型网关、MATLAB 执行器和既有状态机；确定性协调器不引入第三个模型 Agent。首期包括六种检验、FDR/GRF、内部及外部体积指标、图谱定位、ROI 描述、结果解释和报告导出。每份设计一个目标检验或对比；ANOVA/ANCOVA 为总体 F。重复测量、混合效应、置换、多对比联合校正和文献机制解释不属于本计划。

下表按原始范围记录最终证据。确定性和故障场景由回归测试验证，真实数值、软件入口和完整服务流程由独立合成 MATLAB 验收验证；两类证据分别列出，不用 Mock 代替真实计算。详细运行编号、误差及本地证据目录见[验收记录](../development/mvp-verification.md)。

## 可复现验收工具

`scripts/serve-work-statistics-acceptance.py --real-matlab --output-root <新目录>` 生成六张合成指标、项目、空 Work 会话和标记 Mock 模型。检查、纳入、设计、审批及启动从实际网页操作；公共 Worker 执行真实 MATLAB。`--resume` 只复用该工具已有目录，不重写输入或自动创建统计计划。模型发现使用本机 Mock 模型目录，不访问外部服务。

`scripts/verify-work-statistics-acceptance.py --output-root <目录> --run-id <网页运行编号>` 独立读取实际服务，下载并验证产物大小/哈希，对原始合成影像计算解析 T 图与 ROI 均值并核对 AAL 定位。该验收不验证真实 Provider 的规划质量或真实 ASD/HC 研究差异。

增加 `--verify-duplicate-request` 时，额外发送明确选择 Mock 的重复启动请求，要求服务端返回已有任务冲突且运行集合不变；正常验收路径仅查询和下载，不提交运行。

`scripts/verify-statistical-capabilities.py` 补单样本、偏相关、回归、ANCOVA 的公共 Worker 独立数值证明；`scripts/verify-statistical-interpretation.py` 在只读既有真实结果的克隆数据库中验证 Mock Work 事实和审计，`--without-tools` 验证单次路径。两者保留已有验收边界，不把 Mock 解释当真实模型质量证明。

`scripts/verify-grf-estimated-smoothness.py` 以已有授权合成T图的独立副本验证DPABI及当前模板的estimated分支；不修改原图、软件安装或已有运行。`scripts/serve-internal-statistics-browser.py` 只读已通过合成预处理验收的数据库，并复制其工作目录到新目录，供网页重新完成独立统计方案、审批及公共Worker真实执行；原验收数据库与产物保持不变。

`scripts/verify-internal-statistics.py --real-matlab --output-root <新目录>` 生成六份合成原生空间时间序列，执行真实预处理、合成 QC 确认、完整交接、独立统计确认及公共 Worker，独立核对 T 图和源文件哈希。`--resume-source` 仅复用该工具已完成并批准 QC 的来源，拒绝活动或已有成功统计结果的目录；不修改输入或既有 QC。本工具的 Work 提案来自确定性服务，不声称内部网页或真实模型规划已验收。
