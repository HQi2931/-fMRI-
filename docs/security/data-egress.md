# 模型数据外发策略

外部模型只能接收完成当前解释或计划任务所需的去标识化结构摘要。

## 禁止外发

- DICOM、NIfTI、截图、二进制内容或逐体素数据。
- 姓名、患者号、原始 subject ID、邮箱、电话和地址。
- 原始人口学行、绝对路径、完整日志和文件清单。
- API Key、Token、密码和本机私有配置。

## 允许外发

- 汇总数量、数据格式类别和匿名 QC 统计。
- 经过映射的临时受试者伪名。
- 已注册 Skill 名称、结构化参数来源和 ValidationIssue。
- 不含路径和标识的运行错误摘要。

`OutboundContextPolicy` 递归移除禁止字段、伪名化 subject ID、替换路径和联系方式，并对最终 JSON 再扫描。包含患者/姓名/住院号等临床标记、年龄/性别组合或其他无法可靠证明已脱敏的自由文本会在 Provider 调用前整体拒绝，不尝试部分替换后继续发送。无法处理的类型、过深结构或过大逐行列表同样失败关闭。审计只保存 context hash、Provider、模型、时间和路由结果，不保存密钥或完整外发正文。

Provider fallback 只处理传输、限流和服务不可用；Schema 错误只允许同一 Provider 修复一次，不因内容错误静默切换 Provider。
