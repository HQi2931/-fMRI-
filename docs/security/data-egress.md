# 模型数据外发策略

- 状态：Accepted
- 文档类型：Security
- 维护者：qa_reviewer
- 更新日期：2026-09-27
- 关联：[Provider 配置与 smoke](../operations/provider-setup.md)

外部模型只能接收完成当前解释或计划任务所需的去标识化结构摘要。

## 禁止外发

- DICOM、NIfTI、截图、二进制内容或逐体素数据。
- 原始 subject ID、邮箱、电话和路径中的本机目录信息；显式结构化身份字段会丢弃或伪名化。
- 原始人口学行、绝对路径、完整日志和文件清单；工作区文件助手按本文件的显式授权和范围规则读取的脱敏片段除外。
- API Key、Token、密码和本机私有配置。

## 允许外发

- 汇总数量、数据格式类别和匿名 QC 统计。
- 经过映射的临时受试者伪名。
- 已注册 Skill 名称、结构化参数来源和 ValidationIssue。
- 不含路径和标识的运行错误摘要。
- 用户输入的研究问题和工作区文件助手按当前授权、用户选定范围及受控格式解析读取的文本片段。研究数据按用户说明不含真实身份信息。

`OutboundContextPolicy` 递归移除受限字段、伪名化结构化 subject ID、替换路径和联系方式，并拦截凭据样式文本。研究对话中的临床词汇、年龄描述和中文姓名句式不再触发整段拦截；系统依赖用户保证实验数据不含真实身份信息。无法处理的类型、过深结构或过大逐行列表仍会失败关闭。审计只保存 context hash、Provider、模型、时间和路由结果，不保存密钥或完整外发正文。

Provider fallback 只处理传输、限流和服务不可用；Schema 错误只允许同一 Provider 修复一次，不因内容错误静默切换 Provider。

工作区内容授权绑定会话中的规范工作区、Profile 配置修订、具体模型和策略版本。发放授权前，Work 会用一个不含工作区路径、文件名或文件正文的合成工具调用验证所选模型；该请求只有在用户点击授权后才发送。每轮读取前服务端重验授权。文件工具只按需列目录、搜索或分段读取，返回内容仍须脱敏，并作为不可信数据处理。
