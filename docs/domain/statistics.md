## 目标能力

首期支持单样本、两独立样本和配对 t 检验，相关／偏相关，多变量回归，以及单因素 ANOVA/ANCOVA 总体组别 F 检验。每次分析保存不可变 `StatisticalDesignRevision`。

设计至少包含：冻结 subject 顺序、组编码、配对键、图像 Artifact、协变量列、缺失策略、中心化方法、contrast、mask 和 tail。软件版本不属于 `StatisticalDesignRevision` 本体，而由外层 `PlanRevision` 的环境哈希、Skill 锁和 Tool 锁绑定，并随审批一起校验。任何设计字段变化都创建新的统计设计 revision；环境或软件锁变化会使旧计划审批失效，必须重新生成并审批计划。

多重比较与检验分开配置：

- FDR：显式 `q`、tail 和 mask。
- GRF：显式 voxel p、cluster p、tail、mask 与平滑度来源。

目标结果合同包含设计矩阵、contrast、未校正统计图、校正结果、效应量、簇表、参数、日志和完整 provenance。系统不得自动尝试多个方向、阈值或方法后选择更显著结果。

## 当前已接线能力

统计设计 revision 的创建、结构校验、显式审批和审批失效规则已接线。Work 统计草稿由服务端绑定来源运行、QC、指标和人口学证据，再通过独立入口创建、校验、审批及启动运行。DPABI V9.0 的三类 t 检验、`y_Correlation_Image`、`y_GroupAnalysis_Image` 与 `y_ANCOVA1_Image` 均有固定模板适配；相关目标预测量、回归单系数 contrast、ANOVA 组别编码和 F/T/R 校正自由度由结构化设计冻结。六类统计均已在本机 MATLAB R2024b、SPM25、DPABI V9.0_250415 上通过真实执行 smoke；两样本 t + 双侧 FDR、配对 t + GRF、相关 + FDR、三组 ANOVA + GRF 均检查了统计数值与校正产物。能力目录据此登记本机验证状态，真实运行仍要求应用内逐方案确认。

FDR 结果保留 q 和 DPABI 实际 p 截断值，只对双侧 T/R 图开放；GRF 保留体素与簇阈值、尾部、自由度、平滑度来源及 26 邻域连通参数。GRF Z 图、校正统计图和校正证据 JSON 均登记为结果产物。ANOVA/ANCOVA 的 F 图按单尾 GRF 处理，不提供方向解释；FDR 首期不接受 F 图。

GRF 证据另记录实际最小簇、DLH、有效掩膜体素数和来源；头信息或估计分支保留三轴 FWHM（mm），指定 DLH 时 FWHM 未知。方法摘要只从已核验登记文件读取实际值；缺字段的历史结果明确未记录。分析 Agent 使用有界方法、定位及 ROI 聚合事实，零显著体素正常报告无脑区可定位，不能证明组间等价；总体 F 不赋组间方向，显著簇内 ROI 仅作同一数据的描述性展示。

结果登记会从经哈希验证的 `clusters.tsv` 读取簇编号、范围、峰值、推断来源及方向，并将簇绑定到校正图或未校正图。空簇表是有效结果。对已校正结果，登记时还会核对校正图中的非零显著体素数与簇表体素总数；当二者均为零时，结果状态明确为“未发现通过本次校正阈值的显著差异体素”，显著体素数为 0，且没有显著簇或可定位脑区。此时空间定位不适用，不报告为空间未知。F 图簇不赋予组间正负方向；FDR 的簇表仅作空间汇总。只有存在可报告簇时，才需要检查空间证据；簇坐标空间来自冻结指标的服务端谱系，缺少空间证据时记录为 `unknown` 并阻止脑区定位。

Work 方案面板可从本机 DPABI `Templates` 中选择 AAL、AAL3 或 Brodmann 图谱；正式方案与复现报告冻结选择和内容哈希，结果面板沿用该选择。定位前再次验证结果图 Artifact 的路径与哈希，并要求结果与图谱声明同为 MNI；按统计图坐标复核峰值统计量和簇体素数，再用图谱 NIfTI 仿射的逆矩阵最近邻映射簇内每个体素，汇总峰值标签与整簇脑区覆盖比例。响应包含图谱标签、标签编号、体素中心距离和图谱文件指纹。覆盖比例以簇总 voxel 数为分母，背景及图谱范围外体素计入未标注项；它描述空间重叠，不构成额外的统计推断或空间配准验证。

统计结果工作台提供簇表与轴向切片联动：簇峰值的世界坐标经统计图仿射映射到原图层号，点击簇行跳转到对应层，滑块允许检查相邻层；预览使用与产物相同的哈希校验和路径权限。统计图、CSV/TSV 簇表以及 Markdown/JSON 复现报告均可下载。图谱面板在峰值定位外展示整簇标签覆盖。现有 `/cluster-localizations` 接口仍保留为用户显式提供坐标点的通用工具，不参与已登记结果的 DPABI 网格定位。

外部 DPABI 目录通过独立检查和人工纳入凭据进入统计服务。分组目录和站点限定 subject ID 与逐影像哈希一起登记；未知 TR、频带、去噪及平滑信息保持未知。显式选择的 mask 必须与指标图同网格，指标与 mask 都在执行前复制并核对 SHA-256。统计设计绑定导入/纳入哈希，结果空间采用纳入决定中声明的空间。Work 可显式选择外部来源。人口学表按纳入编号独立登记不可变修订；设计冻结 `external_demographics_revision_id/hash`，服务端按影像顺序读取数值，校验中心化、缺失、矩阵秩与自由度。新表修订使旧方案失效；分组仍来自影像纳入凭据。导入时显式选择 grouped 或 paired_conditions 布局；配对布局的一级目录为两个条件，编号集合必须完全一致。每张影像按 subject_id 与 condition 绑定引用，配对条件顺序决定差值方向。静态受试者协变量与 DPABI 配对模型的受试者回归项共线，首期配对 t 不接受此类协变量。设计见 [ADR 0025](../adr/0025-external-statistical-inputs.md) 和 [ADR 0026](../adr/0026-external-demographics-revisions.md)。

`StatisticalResultManifest` 的真实模式要求设计矩阵、contrast、未校正图、按需校正图、effect map、簇表、执行日志与软件版本证据全部存在，且簇连通性必须显式声明；缺失时失败关闭。合成模式只允许醒目标记的非科学占位证据，不能用于推断。

新真实统计 Worker 另外登记实际运行脚本、bootstrap、运行配置及输入清单；清单记录实际暂存文件的大小和 SHA-256。执行前冻结这些文件，成功后复核没有变化；登记及下载继续验证产物边界与哈希。四类证据一旦出现必须完整，报告收录对应角色；历史结果缺少它们时不补造脚本。来源已成功的预处理计划使用历史环境锁复核，新统计审批继续绑定当前环境，见 [ADR 0035](../adr/0035-statistics-producer-environment.md)。
